# 真机验收清单（Pico Neo3）

> 自动化测试覆盖逻辑与稳定性，**手感与舒适度只能真机确认**。建议每次发版按下表走一遍，记录结果。

## 环境
- [ ] 头盔与运行服务器在同一 Wi-Fi（或直接使用 GitHub Pages 在线版）
- [ ] 浏览器地址为 `https://`（WebXR 必需安全上下文）
- [ ] 首次安装 CA 或已点「高级 → 仍要继续」
- [ ] 电量 > 30%，头显空间充足

## 启动与引导
- [ ] 打开页面出现「拾径」入口，点「开始游走」正常进入
- [ ] 首次进入弹出 3 步新手引导，扣扳机能关闭
- [ ] 第二次进入不再弹引导
- [ ] ENTER VR 按钮可见且能进入沉浸模式

## 操作（左右手各测一次）
- [ ] 手柄射线可见，瞄准相邻节点出现脉冲光环
- [ ] 扣扳机可走到相邻节点（滑翔模式有过程感）
- [ ] 握键可呼出设置菜单，射线可点选
- [ ] 菜单切「瞬移」后，扣扳机一步到位（无中间过程）
- [ ] 摇杆左右推一次转 30°，回中后才能再转
- [ ] 收词有震动反馈，走路有轻微震动

## 视觉与音频
- [ ] 三套皮肤切换后颜色正确、文字可读
- [ ] 四类词包切换后自动换主题（诗词→朱砂、极客→青瓷）
- [ ] 收词声有方位感（左/右转头可分辨）
- [ ] 音量滑杆有效，静音后无声音
- [ ] 防晕遮罩在滑翔时边缘变暗，关闭后无遮罩

## 座姿与长时间
- [ ] 坐姿游玩：点「座姿标定」后节点高度舒适
- [ ] 连续游玩 30 分钟无眩晕、无视野遮挡
- [ ] 30 分钟后帧率无明显下降（可对比启动时）

## 结算与数据
- [ ] 胜利/失败均生成结算海报，可下载 PNG
- [ ] 「重放路径」可播放并跳过
- [ ] 存档导出→清空→导入后战绩/词集恢复
- [ ] 每日挑战完成后再进显示「已完成 · 连续 N 天」
- [ ] 点击 7 日柱状图可打开月视图

## 异常场景
- [ ] 快速连续扣扳机不卡死、不重复计分
- [ ] 中途按 Home 返回再进入，进度不丢
- [ ] 断网（在线版）后页面提示合理，不白屏
