# 拾径 · Wordloom v1.2.2 发布说明

发布日期：2026-11-13

## 本版新增

- **卡片二维码**：成就卡 / 周报 / 统计卡右下角附在线版二维码（qrcode-generator 2.0.4，MIT，本地 vendor，离线可用）
- **生涯统计卡**：统计面板一键导出 1080×1350 PNG（6 项核心指标 + 分难度战绩 + 二维码）
- **分享文案**：统计 / 成就 / 周报三处「复制分享」，一键生成带在线地址的挑战文案
- **离线打包修复**：qrcode 以 base64 data-URI 注入单文件 HTML，离线版保持自包含
