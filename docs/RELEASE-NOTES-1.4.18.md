# 拾径 · Wordloom v1.4.18 发布说明

发布日期：2026-11-16

## 本版新增：挑战模式

- 引导页新增「🎭 挑战」：一局同时开启**迷雾 + 限时**（标准难度 90 秒）
- 结束时自动恢复用户原先的迷雾/限时开关，不污染日常设置
- 本地记录挑战最佳分（`rw-combo-best`，只升不降），统计面板展示
- 与其他模式互斥：挑战局不写入每日/每周成绩
- 胜利可解锁「双重考验」成就
