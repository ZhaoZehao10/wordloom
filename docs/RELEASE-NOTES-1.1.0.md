# 拾径 · Wordloom v1.1.0 发布说明

发布日期：2026-11-12

## 亮点

- **双挑战模式**：每日挑战（按日固定词图）+ 每周挑战（按 ISO 周固定词图），各自独立记录
- **连续打卡**：连续 3/7 天给每日挑战 +1/+2 步，连续 7 天解锁「七日不辍」
- **主题词包**：经典 / 诗词 / 极客 / 自然 / 混合，切换自动套用配套皮肤与音色
- **元进度**：13 个成就（含词包全集、跨难度、连续打卡）、词集 120 词、各词包进度条、成就总览
- **每日 7 日榜 + 月视图**：柱状图、整月日历、历史最佳
- **沉浸体验**：VR 内设置菜单、滑翔/瞬移、快转、空间音效、震动、防晕遮罩、座姿标定、路径回放
- **结算海报**：1080×1620 PNG，含路径诗、一言、本局成就与生涯成就进度
- **三种交付形态**：局域网 HTTPS、单文件离线 HTML、离线 APK（`com.wordloom.roam`）
