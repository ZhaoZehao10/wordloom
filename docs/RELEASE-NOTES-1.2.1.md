# 拾径 · Wordloom v1.2.1 发布说明

发布日期：2026-11-13

## 本版新增

- **生涯统计面板**：总局数、胜场、胜率、最佳分、平均步数、累计收录词次、三种难度各自战绩；入口在词集面板「📊 统计」
- **存档校验和**：导出带 FNV-1a 校验和，篡改或损坏的存档会被拒绝；旧存档仍可导入
- **词集成就提示**：词集面板显示距「词集三十 / 词汇全图」还差多少词
- **周榜 CSV 导出**：月视图一键导出最近 8 周成绩（`week,score,win`）
