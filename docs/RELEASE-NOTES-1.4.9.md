# 拾径 · Wordloom v1.4.9 发布说明

发布日期：2026-11-15

## 本版新增

- **存档密码保护（可选）**：
  - 导出时填写 ≥4 位密码，使用 **PBKDF2-SHA256（15 万次）+ AES-256-GCM** 加密存档
  - 导入加密存档时输入密码解密；密码错误或内容被篡改会明确拒绝
  - 不填密码仍导出普通 JSON，完全兼容旧流程
- 词集面板新增「存档密码」输入框（仅本地使用，不上传）
- 修复离线打包对 `export async function` 的剥离规则
