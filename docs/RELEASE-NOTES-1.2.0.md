# 拾径 · Wordloom v1.2.0 发布说明

发布日期：2026-11-12

## 本版新增

- **存档 v2**：导出/导入包含成就解锁、每日与每周挑战进度及历史；兼容 v1 旧存档，换设备完整恢复
- **周报海报**：月视图内一键导出 1080×1350 PNG（最近 8 周柱状图 + 已挑战周数 / 最佳 / 总分）
- **生涯成就卡**：成就总览页一键导出 1080×1350 PNG（15 个成就解锁一览 + 进度条）
- **新成就**：「☀️ 日冠军」（赢下一局每日挑战）、「🏆 周冠军」（赢下一局每周挑战）
- **每周本地榜**：月视图展示最近 8 周成绩
- **性能报告**：历史最佳/最差帧率对比
