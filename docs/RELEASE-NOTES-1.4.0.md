# 拾径 · Wordloom v1.4.0 发布说明

发布日期：2026-11-14

## 本版新增

- **迷雾模式**：引导页「🌫 迷雾」开关（跨局记忆），只显示当前节点与相邻节点的标签；目标 1024 始终可见
- **模式成就**：
  - 🌫「雾中行者」：迷雾模式下赢下一局
  - ⏱「争分夺秒」：限时模式下赢下一局
- 成就总数增至 **18**
