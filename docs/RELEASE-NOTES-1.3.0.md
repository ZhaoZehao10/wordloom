# 拾径 · Wordloom v1.3.0 发布说明

发布日期：2026-11-14

## 本版新增

- **限时模式**：引导页「⏱ 限时」开关（跨局记忆），按难度倒计时——悠然 120 秒 / 标准 90 秒 / 紧绷 75 秒
- **倒计时 HUD**：游戏内显示 `mm:ss`，倒计时结束自动判负
- **结算标注**：限时局结算页显示「⏱ 限时」
- 纯函数 `roundTimer` 与边界单测
