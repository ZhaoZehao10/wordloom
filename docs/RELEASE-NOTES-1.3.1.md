# 拾径 · Wordloom v1.3.1 发布说明

发布日期：2026-11-14

## 本版新增

- **限时最佳成绩**：按难度分别记录限时模式最高分（只升不降），统计面板展示
- **最近对局列表**：统计面板显示最近 6 局的日期、难度、胜负与分数
- **月视图翻月**：每日挑战月历支持「上个月 / 下个月」切换
